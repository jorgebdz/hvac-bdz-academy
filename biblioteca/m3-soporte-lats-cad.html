Procedimiento seguro para incidencias

Volver a Sesión 3.1

Regla de seguridad

No descargues DLL/OCX desde sitios desconocidos, no desactives antivirus o Smart App Control como procedimiento del curso y no copies archivos arbitrariamente a System32/SysWOW64.

Error mfc100u.dll

Si LATS-CAD.exe indica que no se encontró mfc100u.dll, toma una captura del mensaje. El archivo corresponde al runtime Microsoft Visual C++ 2010. La corrección debe hacerse mediante el redistribuible oficial correspondiente; para una aplicación antigua de 32 bits, iniciar con x86, reiniciar Windows y volver a probar.

Si aparece un error diferente después, detente y documenta el nuevo mensaje antes de instalar otra cosa.

Diagnóstico

1. Captura del error. 2. Registrar versión de Windows. 3. Confirmar procedencia del instalador. 4. Instalar sólo prerrequisitos oficiales. 5. Reiniciar. 6. Probar de nuevo. 7. Reportar el nuevo mensaje si persiste.
