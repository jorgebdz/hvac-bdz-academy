Magnitudes y unidades

Hablen con precisión

  • Q: caudal en CFM (ft³/min).
  • V: velocidad en PPM (pies/min).
  • A: área transversal ft²; W, H y D: pulgadas.
1 ft² equivale a 144 in².
DISEÑO: PLANO → DATOS → SOFTWARE → RESULTADO → INTERPRETACIÓN · Caso ductado alternativo, cuando corresponda.
HVAC BDZ ACADEMY · MÓDULO 4 · SESIÓN 4.2 · 7/34

La ecuación fundamental

CFM = área × velocidad

  • A_req (ft²) = Q (CFM) / V (PPM).
  • La velocidad es un criterio de diseño, no una constante universal.
Q=600 y V=600 permiten A=1.00 ft².

Ducto rectangular: geometría

Ancho y peralte

  • Área = W × H / 144.
  • Despeje H_calc = 144 × Q / (V_obj × W).
  • H_comercial: redondeo superior según medida disponible.
Después de redondear vuelvan a calcular V_real.
DISEÑO: PLANO → DATOS → SOFTWARE → RESULTADO → INTERPRETACIÓN · Caso ductado alternativo, cuando corresponda.

Ejemplo rectangular resuelto

600 CFM · 600 PPM

  • A_req = 600/600 = 1.00 ft².
  • Si W=12 in, entonces H=144×1/12=12 in.
  • Área real = 12×12/144=1.00 ft²; V_real=600 PPM.
Resultado geométrico preliminar: 12 × 12 pulgadas.

Cambiar velocidad cambia el ducto

Relación inversa

  • Para 600 CFM: 600 PPM → 1.00 ft².
  • Para los mismos 600 CFM: 400 PPM → 1.50 ft².
  • Más área exige mayor espacio y material.
Velocidades objetivo se justifican por el tipo de tramo.

Ducto circular: sección

Qué cambia respecto al rectangular

  • Se calcula la misma área necesaria.
  • Área circular (ft²) = πD²/(4×144).
  • D se expresa en pulgadas.
No usar la fórmula rectangular para circular.
DISEÑO: PLANO → DATOS → SOFTWARE → RESULTADO → INTERPRETACIÓN · Caso ductado alternativo, cuando corresponda.
HVAC BDZ ACADEMY · MÓDULO 4 · SESIÓN 4.2 · 14/34

Ducto circular: despeje

Diámetro teórico y comercial

  • D_teórico (in) = √[576Q/(πV)].
  • Redondear diámetro hacia arriba según medida comercial.
  • V_real=Q/[πD²/(4×144)].
El diámetro comercial puede modificar la velocidad real.

Rejilla: área frontal y libre

Identifiquen sus dimensiones

  • Área de frente = W×H/144.
  • Área libre = A_frente×f_libre.
  • La fracción libre es dato del modelo/fabricante.
No confundir área frontal con área libre.
