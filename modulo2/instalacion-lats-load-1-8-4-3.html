Meta de instalación

LATS Load abre → Create Project funciona → Room Information está disponible.

Ruta resumida

  1. Ingresa desde el botón Instalador controlado · LATS Load 1.8.4.3 de la Sesión 2.3.
  2. Descarga el instalador desde el enlace oficial del curso.
  3. Ejecuta el asistente InstallShield y completa la instalación.
  4. Abre LATS Load y verifica Create Project y Room Information.
  5. Conserva una captura del programa abierto como evidencia.

Seguridad

Utiliza únicamente el instalador distribuido desde HVAC BDZ Academy. No descargues DLL/OCX de páginas externas, no desactives antivirus y no copies archivos arbitrariamente a System32/SysWOW64. En equipos empresariales respeta las políticas de TI.

Si aparece Compass.ocx

  • Toma una captura completa.
  • No descargues Compass.ocx de terceros.
  • No lo registres manualmente por tu cuenta.
  • Reporta al instructor/TI para el procedimiento controlado.
  • Si no se resuelve en el bloque técnico, sigue la clase por pantalla compartida y recibe soporte posterior.
