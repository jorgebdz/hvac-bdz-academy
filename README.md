# HVAC BDZ Academy

Portal público del participante para el Curso HVAC BDZ.

## Módulo publicado

- Módulo 1 — Historia y Fundamentos HVAC
- Clase en vivo por Zoom
- Evaluación diagnóstica en Google Forms
- Actividad formativa en Google Forms
- Evaluación final en Google Forms
- Encuesta de cierre en Google Forms
- Materiales del participante publicados como páginas web internas del portal

## Nota de seguridad

Este repositorio contiene únicamente el portal público del participante.  
Los documentos internos del instructor, rúbricas, claves de respuesta y controles administrativos no se publican en este sitio estático.

## Ejecución local

```bash
npm install
npm start
```

Después abre:

```text
http://localhost:3000
```
