Instalación de LG LATS Load 1.8.4.3

Soporte técnico controlado · No forma parte de las horas académicas

Meta

LATS Load abre → Create Project funciona → Room Information está disponible.

Ruta preferida

  1. Guarda LATS-Load+1.8.4.3.exe en una carpeta local de Windows.
  2. Cierra una versión anterior si está abierta.
  3. Ejecuta el instalador con doble clic.
  4. Sigue el asistente con opciones normales. En equipo empresarial respeta las políticas de TI.
  5. Reinicia sólo si el instalador lo solicita.
  6. Abre LATS Load y verifica Create Project y Room Information.
  7. Envía una captura del programa abierto.

Seguridad

No descargues DLL/OCX de páginas externas, no desactives antivirus y no copies archivos arbitrariamente a System32/SysWOW64.

Si aparece Compass.ocx

  • Toma captura completa.
  • No descargues Compass.ocx de terceros.
  • No lo registres manualmente por tu cuenta.
  • Reporta al instructor/TI para el procedimiento controlado.
  • Si no se resuelve en el bloque técnico, sigue la clase por pantalla compartida y recibe soporte posterior.
