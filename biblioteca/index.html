Cómo usar esta biblioteca

Esta biblioteca está pensada para que el participante pueda estudiar los conceptos de clase y también tomar ideas para documentar proyectos reales. Cada manual incluye explicación técnica, fórmulas, variables, ejemplos, diagramas, tablas, errores comunes, checklist y guía para redactarlo en una memoria técnica.
